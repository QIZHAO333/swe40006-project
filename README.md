# SWE40006 Study Board

A Flask and PostgreSQL web application for managing university study sessions.

## Tools

GitHub, GitHub Actions, Docker, PostgreSQL, AWS EC2 and CloudWatch.

## Run locally

```powershell
flask --app app run --host 0.0.0.0 --port 8000
```

Open <http://localhost:8000>. Health check: <http://localhost:8000/health>.

## Git workflow

Create a branch, commit and push changes, then open a pull request for review before merging into `main`.
